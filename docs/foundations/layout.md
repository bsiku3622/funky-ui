# Layout

요소 **사이**의 관계 — 간격, 깊이(그림자와 쌓는 순서), breakpoint, 폭 — 를 정리한 문서입니다. 숫자의 정본은 `tokens/layout.ts`입니다.

## 간격

안쪽 여백(padding)과 형제 사이(gap)는 같은 사다리를 씁니다. 같은 이름이면 같은 길이입니다.

| 이름 | px | | 이름 | px |
| --- | --- | --- | --- | --- |
| `0` | 0 | | `xl` | 16 |
| `2xs` | 2 | | `2xl` | 20 |
| `xs` | 4 | | `3xl` | 24 |
| `sm` | 6 | | `4xl` | 32 |
| `md` | 8 | | `5xl` | 48 |
| `lg` | 12 | | `6xl` | 64 |

Tailwind 단위로 옮기면 `gap-1.5`가 `sm`, `p-5`가 `2xl`, `p-6`이 `3xl`입니다. 카드의 기본 안쪽 여백은 `3xl`(24px)입니다.

## 깊이

그림자는 **두 단뿐**입니다. 떠 있는 물건은 4px, 모달만 6px입니다. blur는 언제나 0이고, 색은 `rgba(0,0,0,.2)` 하나입니다.

| 단 | 그림자 | 쓰는 곳 |
| --- | --- | --- |
| `raised` | `4px 4px 0 0` | 카드 · 떠 있는 버튼 · 메뉴 · 툴팁 |
| `floating` | `6px 6px 0 0` | 모달 |

class-explorer를 계측했을 때 서로 다른 그림자 값이 33개였습니다(2px · 3px · 4px · 6px · 8px에 투명도 0.05 ~ 0.3, blur 15px 하나). 깊이가 33단계인 화면은 없으므로 전부 이 두 단으로 모읍니다. 카드의 6px도 4px이 됩니다(6px는 모달 몫입니다).

쌓는 순서(z)는 아래 일곱 칸입니다. 이웃 위에 한 단 서는 것(골라진 칸)과 화면에 고정되는 것(바 · 드롭다운 · 덮개 · 토스트 · 툴팁)으로 나뉩니다. 모달은 native `<dialog>`의 top layer가 맡아서 z 값이 없습니다 — class-explorer의 `z-50`부터 `z-[1100]`까지 흩어진 값이 여기서 정리됩니다. 떠 있는 판(Floating)은 `dropdown` · `tooltip` 중 하나를 고르고, 모달 안에서 열리면 그 모달 안에 그려져 모달 위에 섭니다.

| 이름 | z | 쓰는 곳 |
| --- | --- | --- |
| `base` | 0 | 바닥 |
| `raised` | 1 | 골라진 칸(Selectable `grow`)이 나란한 이웃 위에 섭니다 — class-explorer의 `z-10` |
| `sticky` | 100 | 상단 바 · 하단 바 |
| `dropdown` | 200 | 메뉴 · 팝오버 · 검색 제안 · Floating의 `scrim` |
| `overlay` | 300 | 덮개 · 서랍(Drawer) |
| `toast` | 400 | 알림 |
| `tooltip` | 500 | 설명 풍선 |

## Breakpoint

Tailwind 기본과 같은 값입니다(sm 640 · md 768 · lg 1024 · xl 1280). class-explorer의 `md:`와 어긋나지 않습니다. 미디어 쿼리는 변수를 읽지 못하므로 값으로 씁니다.

## 폭

| 이름 | px | 쓰는 곳 |
| --- | --- | --- |
| `prose` | 720 | 읽는 글 한 단 |
| `dialog.sm · md · lg · xl · full` | 400 · 512 · 768 · 1024 · 1280 | 모달. `full`은 높이도 96vh로 잡아 화면을 거의 덮습니다 |
| `shell.bar` | 80 | 상단 바 높이 |
| `shell.sidebar` | 256 | 사이드바 폭 |
| `shell.bottomBar` | 64 | 하단 바 높이 |
